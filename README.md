# SnapFind Studio

Create a modern, smooth, eye-catching mobile-first web/app called “SnapFind” — a photographer finder marketplace that helps clients discover, compare, book, and pay photographers.

CORE PURPOSE:
The app connects clients looking for photography services with photographers in their area. Photographers create profiles, display portfolios, set prices, list services, receive bookings, and get paid through the platform.

DESIGN / UI:
- Create a premium, modern photography-focused interface.
- Use large, high-quality photography previews, clean cards, rounded corners, subtle shadows, smooth transitions, and elegant animations.
- Make the UI feel fast, simple, professional, and visually attractive.
- Use a clean black/white base with photography-inspired accent colors.
- Make navigation extremely easy on both mobile and desktop.
- Use smooth loading states, skeleton screens, hover effects, swipeable photo galleries, and animated buttons.
- Photographer portfolio images should be the visual focus of the app.
- Include both light mode and dark mode.
- Make the interface feel similar to a premium creative marketplace rather than a generic directory.

BADGE SYSTEM:
Create TWO completely different badge systems.

A. PROFESSIONAL / TRUST BADGES:
These badges represent qualifications, verification, experience, achievements, or trust signals. They must NOT be connected to paid promotion.

Examples:
- Verified Photographer
- ID Verified
- Portfolio Verified
- Business Verified
- Top Rated
- Experienced Photographer
- Fast Responder

These badges should be earned through platform criteria, admin verification, reviews, completed bookings, or uploaded documentation.

B. PAID PROMOTED BADGE:
Create a completely separate badge called:

“PROMOTED”

This is a paid visibility feature and must look visually different from professional/verification badges.

Pricing:
- R100 per month
- Monthly subscription
- Photographer can activate or cancel it from their dashboard.

PROMOTED BADGE BEHAVIOUR:
When a photographer pays R100/month for the Promoted badge:
- Their profile receives higher visibility in relevant search results.
- Their profile can appear closer to the top of search results.
- Promoted profiles should still match the client's selected location/category/filter.
- Do NOT make payment override relevance.
- Clearly label promoted profiles as “Promoted” so users understand that the higher placement is paid.
- The Promoted badge must never look like a verification badge.
- Make the design visually distinct, for example with a small “Promoted” pill and a subtle advertising/boost icon.
- Show the subscription status and renewal date in the photographer dashboard.

PAYMENT AND PLATFORM FEES:

When a client books and pays a photographer, apply the following:

1. CLIENT SERVICE FEE:
Add a fixed R15 service fee to the client's payment.

Example:
Photographer price = R1,000
Client service fee = R15
Total paid by client = R1,015

2. PHOTOGRAPHER PLATFORM COMMISSION:
Take 10% of the photographer's booking amount.

Example:
Booking amount = R1,000
Platform commission = 10% = R100
Photographer receives = R900

The R15 client service fee is separate from the 10% photographer commission.

DISPLAY THIS CLEARLY:
Photographer booking price: R1,000
Client service fee: R15
Client pays: R1,015
Platform commission: R100
Photographer receives: R900

Create automatic fee calculations throughout the checkout system.
